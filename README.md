# BY Run 长跑社 · 网站维护手册

这是一个**纯静态网站**：没有后端、没有数据库、没有构建步骤。
所有文件都是普通的 HTML / CSS / JavaScript，改完直接提交即可生效。

---

## 一、日常更新：每天只改一个文件

**`assets/js/data/daily.js`** —— 公告栏和训练计划都在这里。

### 操作步骤（全程在浏览器里完成）

1. 打开仓库地址，例如 `https://github.com/你的用户名/byrun`
2. 依次点进 `assets` → `js` → `data` → `daily.js`
3. 点右上角的 **铅笔图标**（Edit this file）
4. 修改内容（写法见下）
5. 拉到页面最底部，在说明框里写一句人话，例如 `更新10月12日公告`
6. 点绿色按钮 **Commit changes** → 再点一次确认
7. 等 **1–3 分钟**，刷新线上网站即可看到

> 手机上用浏览器打开 GitHub 也能完成同样操作。

### 写公告

格式：`日期 | 标题 | 正文`
最新的写在**最上面**。网页会自动按日期倒序排列，写乱顺序也没关系。

```
2026-10-12 | 周二加练通知 | 18:30 西操场集合，内容为间歇跑 8×400m，请提前热身。
2026-10-11 | 本周六早训调整 | 集合时间提前至 7:00，请统一着队服。
```

### 写训练计划

格式：`星期 | 时间 | 地点 | 内容`
休息日可以写成 `周一 | 休息 | - | 自行恢复跑`，网页会自动把它显示成虚线框。

```
周二 | 18:30 | 西操场 | 慢跑 5km + 动态拉伸
周六 | 7:00 | 校外绿道 | 长距离 12–16km，注意补水
```

### 三条必须遵守的规则

1. **不要删除文件里的反引号 `` ` ``**（每一段开头和结尾的那两个弯引号），也不要删掉 `window.ANNOUNCEMENTS =` 这类开头。删了整栏就会变成空白。
2. **一行写一条**，不要把一条公告拆成好几行。
3. **以 `#` 开头的行是备注**，网页上不会显示，可以随便用来给自己做标记。

## 三、怎么加照片

相册的照片需要**两个动作**，是全站最繁琐但也就一次的事。

1. **先压缩照片**（见下一节），重命名成英文，例如 `2026-10-12-xishan-01.jpg`。
2. 在 GitHub 网页端进入 `assets` → `img` → `gallery` 文件夹。
3. 点 **Add file → Upload files**，把图片拖进去，提交。
4. 回到 `assets/js/data/gallery.js`，在列表里加一行：

```
2026-10-12-xishan-01.jpg | 西山越野赛出发 | 2026-10-12
```

5. 提交。完成。

> 文件名必须和你上传的**完全一致**，包括大小写。GitHub 的服务器区分大小写，本地不区分。

### 换掉占位图

现在相册里有 6 张写着「活动照片占位」的灰色图片。上传真实照片并加好数据行之后，
把 `gallery.js` 里对应那几行 `gallery-01.svg … gallery-06.svg` 删掉即可。

### 换招新二维码

把你的招新群二维码保存为 **`join-qr.png`**，上传到 `assets/img/` 目录。
网页会自动优先显示它，不需要改任何代码。
（现在显示的是占位图 `join-qr.svg`，真实图片到位后自动替换。）

## 四、图片压缩清单

GitHub Pages 有硬性限制：**单个文件 ≤ 100 MB，整站 ≤ 1 GB**。
跑团网站照片多，务必先压缩，否则仓库会越来越臃肿、加载越来越慢。

| 项目 | 建议值 |
|---|---|
| 单张照片大小 | **≤ 300 KB** |
| 长边像素 | ≤ 2000 px |
| 格式 | JPG（照片）或 WebP（更小） |
| 命名 | 纯英文 + 数字 + 连字符，如 `2026-10-12-xishan-01.jpg` |

**压缩办法（任选一种）**

- 手机：微信发送图片时选择「原图」以外的方式会压缩，但不稳定，建议用专门工具。
- 电脑：Windows 自带「照片」应用 → 另存为 → 调整大小；或用免费工具如 Squoosh（网页版，浏览器搜索即可）。
- 在线批量：搜索「图片批量压缩」，任选一个上传后下载。

⚠️ 不要在文件名里使用中文、空格或括号。例如 `西山照片 (1).jpg` 会出问题，
请改成 `2026-10-12-xishan-01.jpg`。

## 五、发布到 GitHub Pages（首次配置）

1. 注册并登录 [GitHub](https://github.com)。
2. 右上角 **+** → **New repository**。
   - Repository name 填 `byrun`（或你喜欢的英文名）
   - 可见性选择 **Public**（必须公开，私有仓库用 Pages 需要付费）
   - 不要勾选自动创建 README
3. 创建后在仓库页点 **Add file → Upload files**，把本项目**所有文件和文件夹**拖进去，提交。
   - 注意：要连同 `assets` 整个文件夹、`.nojekyll` 一起上传。
   - `.nojekyll` 是隐藏文件，如果拖拽时看不到，在网页上传界面它也会被一并带上；
     若确实漏了，就新建一个空文件命名为 `.nojekyll`。
4. 进入 **Settings → Pages**。
   - Source 选择 **Deploy from a branch**
   - Branch 选 `main`，文件夹选 `/ (root)`，点 **Save**
5. 等 1–2 分钟，刷新该页面，顶部会出现你的网址：

```
https://你的用户名.github.io/byrun/
```

把这个网址发给同学即可。

### 后续更新

配置只需做一次。此后每次改动，按第一节的流程在网页端提交，1–3 分钟自动生效。

## 六、改错了怎么办

**别慌，GitHub 保存了每一次修改的历史版本。**

1. 打开被改坏的那个文件（例如 `daily.js`）
2. 点右上角的 **History**（历史记录）
3. 找到改坏之前的那一次提交，点进去
4. 点 **Revert** 或直接查看旧版本内容，把内容复制回来重新提交

整个网站任何文件都可以这样恢复。

## 七、常见问题

**Q：提交后网站没变化？**
等 1–3 分钟。如果超过 5 分钟还没变，刷新页面时按 `Ctrl + F5` 强制刷新（浏览器缓存）。
仍不行就去仓库的 **Actions** 标签页看部署是否报错。

**Q：公告栏 / 训练计划整块变成空白，并提示"数据未加载"？**
多半是误删了 `daily.js` 里的反引号 `` ` ``。按第六节回滚即可。

**Q：照片不显示，只看到一个空的框？**
三种可能：
1. 文件名写错（大小写不一致）—— 最常见；
2. 图片还没上传成功；
3. 图片路径不在 `assets/img/gallery/` 下。

**Q：想改配色怎么办？**
打开 `assets/css/tokens.css`，最上面的 `--brand` 就是品牌主色。
把 `#E8590C` 改成你想要的颜色，全站自动跟着变。

**Q：想换 Logo？**
把新 Logo 覆盖 `assets/img/logo.svg` 即可。建议使用 SVG 或正方形 PNG。

**Q：想改社团名称、学校名？**
各页面里搜索「某某大学」和「BY Run」逐个替换。
`BY Run` 出现在页面标题栏、导航栏左侧与页脚，共约 9 个文件。

**Q：国内访问有点慢或者偶尔打不开？**
这是 GitHub Pages 的固有限制（服务器在境外）。本站是纯静态文件，
可以**零改动**迁移到其它静态托管平台，例如 Cloudflare Pages 或腾讯云 EdgeOne Pages。
详见方案文档第九节。

**Q：能不能让同学在网上直接报名？**
纯静态网站无法接收表单数据。现在的做法是引导同学扫码进群。
若以后需要线上收集，把报名链接指向问卷星 / 腾讯问卷即可，网站本身不用改。

## 八、目录结构说明

```
byrun/
├── index.html          首页
├── about.html          社团介绍 / 章程
├── training.html       训练计划
├── records.html        成绩纪录
├── members.html        成员风采
├── gallery.html        活动相册
├── news.html           公告栏
├── join.html           加入我们
├── 404.html            找不到页面时的提示页
├── .nojekyll           必需的隐藏文件（不要删）
├── README.md           本手册
└── assets/
    ├── css/            样式（tokens=配色变量，其余不用动）
    ├── js/
    │   ├── data/       ★ 你平时要改的就是这里
    │   ├── render.js   把数据渲染成页面（不用动）
    │   ├── common.js   主题切换、菜单、导航（不用动）
    │   └── lightbox.js 相册放大（不用动）
    └── img/            图片素材
```

**给非维护者的提醒**：`assets/css/` 和 `assets/js/` 下除 `data/` 外的文件，
只有在需要调整视觉设计或交互行为时才需要修改。
